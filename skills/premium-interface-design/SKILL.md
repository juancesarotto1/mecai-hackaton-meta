# Premium Interface Design

## Inputs

Require user task, device classes, existing tokens, information hierarchy, interaction list, and accessibility target.

## Procedure

1. Put the 3D work surface first and reveal one clear primary action.
2. Use semantic tokens, a compact 4/8 spacing rhythm, technical typography, and blue/orange accents without relying on color alone.
3. Keep pointer/touch targets usable, focus visible, controls labelled, and canvas alternatives understandable.
4. Adapt secondary panels below the stage on narrow screens and avoid nested scrolling where possible.
5. Respect reduced motion and keep simulation motion stoppable.

## References

Use `design-system/motormind-xr/MASTER.md` and WCAG 2.2 AA.

## Output

Produce implemented responsive UI, states, keyboard paths, and a concise UX verification record.

## Validation

Check 375/768/1024/1440 widths, landscape, zoom, keyboard-only use, focus visibility, 4.5:1 text contrast, 24px web targets or documented exceptions, and reduced motion.
