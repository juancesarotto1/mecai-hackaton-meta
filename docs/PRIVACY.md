# Privacy and data behavior

The judged IWSDK experience is self-contained. It does not request or store names, accounts, contacts, location, camera data, microphone data, biometrics, advertising identifiers, or analytics. Hand poses are consumed by the WebXR/IWSDK runtime for local interaction and are not persisted or transmitted by MotorMind XR.

The separate desktop laboratory includes optional server-side OpenAI routes. When explicitly configured and used, the text a user submits is sent to the configured provider. API credentials remain server-side. These optional routes are not required by the XR mission and should not be enabled in the judged build unless the entrant has completed the corresponding disclosure and policy review.

This document describes the current source implementation and must be rechecked against the exact hosted build before submission.
