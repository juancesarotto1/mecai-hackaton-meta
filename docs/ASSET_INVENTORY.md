# Asset inventory

No external 3D asset is claimed or bundled. The current engine is generated from Three.js primitives with stable semantic IDs. This avoids an unlicensed or monolithic GLB while keeping crank-slider motion, picking and disassembly verifiable.

Before adding a model, record source URL, author, license, commercial permission, file hash, units, polygon count, materials, textures, segmentation, pivots, optimization steps and manifest validation results.
