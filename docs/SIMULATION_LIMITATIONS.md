# Simulation limitations

The mechanism provides Level A geometric kinematics: rigid crank-slider positions, velocities, firing phases, cam ratio and smooth illustrative valve lift. Torque is Level B first-order visualization based on synthetic combustion pulses, friction and load. It is not a pressure trace, thermodynamic solver, acoustic model, calibration tool or diagnostic instrument.

Dimensions belong to a generic educational fixture and must not be attributed to a commercial engine. Torque values show internal model deltas only. Fault explanations are educational hypotheses, never definitive diagnosis or repair specifications.
